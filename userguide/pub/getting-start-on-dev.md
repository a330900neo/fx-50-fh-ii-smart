## 建立Project

開啟fxStudio
- 在開始頁按「New project」

  或
  
- 「Files」>「New project」

填寫基本資料

## 編程語言

功能 | Kotlin | C | Python
---|---|---|---
GUI | ✅ | ✅ | ✅
寫入存儲空間 | ✅ | ✅ | ❎
硬件層直接存取 | ❎ | ✅ | ❎
SuperUser權限調用 | 部分 | ✅ | ❎

選擇適合的語言
