# 快速入門

<img src="/image/startset.png" alt="drawing" height="400"/>

歡迎使用 CASIO fx-50FH II。本指南將協助您完成初次設定。

## 開機與基本操作

按ON即可開機。首次使用時，畫面會引導您完成基本設定:
1. 語言
2. 網絡
3. 智能模式開啟暗號
4. 密碼
5. Firmware update

按ON永遠能返回普通模式

## 注意

- 日後部分操作須在電腦完成

## 常見問題

- 若無法開機，請確認電池已正確安裝及有電
- 若聯網功能無法使用，請檢查Firmware是否已更新至最新版本
