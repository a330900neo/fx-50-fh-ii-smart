# calProtect

<img src="https://raw.githubusercontent.com/a330900neo/fx-50-fh-ii-smart/main/userguide/pub/image/calprotect.png" alt="drawing" height="400"/>

calProtect是一個系統內置的安全軟件，在安裝應用程式時會掃描，定時掃描病毒/不安全程式。

## 如何開啟或關閉 calProtect

請確保你所安裝的程式是安全
1. 進入設定 > 系統 > 進階
2. 進入 「安全」
3. 關閉 「calProtect 安全保護」
4. 按「確定」
